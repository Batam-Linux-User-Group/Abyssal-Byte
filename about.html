PENGERTIAN

Apa Itu Linux?

Singkatnya: Linux adalah inti dari sebuah sistem operasi.

Linux adalah kernel sistem operasi open source yang dibuat Linus Torvalds pada 1991.

Kernel menjembatani aplikasi dengan hardware. Digabung dengan tools GNU dan aplikasi lain, jadilah sistem operasi utuh yang disebut distro, misalnya Ubuntu, Fedora, atau Kali Linux.

kernel
Inti sistem yang mengatur CPU, memori, dan perangkat.
open source
Kode terbuka: boleh dilihat, diubah, dan dibagikan (GPL v2).
distro
Paket siap pakai: kernel + tools + desktop + aplikasi.
Analogi gampangnya

Kernel itu mesin, distro itu mobilnya. Mesinnya sama, model dan fiturnya beda-beda.

FUN FACT

Hampir Bernama "Freax"

Linus menamai proyeknya Freax, tapi Ari Lemmke, admin server FTP tempat kodenya diunggah, memberi nama folder linux, dan nama itulah yang melekat. Maskotnya, penguin Tux, digambar Larry Ewing pada 1996.

SEJARAH

Perjalanan Linux

Dari Unix 1969 sampai era Linux 7. Pilih era untuk menyaring.

1969Akar

Unix lahir di Bell Labs

Dibuat Ken Thompson & Dennis Ritchie. Konsepnya jadi cetak biru Linux.

1983Akar

Proyek GNU dimulai

Richard Stallman merintis sistem operasi bebas. Tools-nya kelak dipakai Linux.

1987Akar

MINIX untuk belajar

OS mini buatan Andrew Tanenbaum, tempat Linus belajar.

25 Agu 1991Kelahiran

Linus mengumumkan Linux

Mahasiswa Universitas Helsinki, 21 tahun, menyebutnya "just a hobby".

1992Kelahiran

Berlisensi GNU GPL

Linux resmi bebas dipakai, diubah, dan dibagikan.

1993Kelahiran

Distro pertama lahir

Slackware dan Debian. Debian kini induk Ubuntu & Kali.

14 Mar 1994Kelahiran

Linux 1.0 rilis

Versi stabil pertama, sudah mendukung jaringan.

2004Berkembang

Ubuntu hadir

Membawa Linux ke pengguna awam.

2005Berkembang

Git diciptakan

Dibuat Linus untuk kode kernel; kini dipakai jutaan developer.

2008Berkembang

Android rilis

Ponsel Android pertama hadir, berbasis kernel Linux.

Nov 2017Modern

100% superkomputer

Seluruh 500 superkomputer tercepat dunia memakai Linux.

2021Modern

Linux terbang di Mars

Helikopter Ingenuity milik NASA menjalankan Linux.

2022Modern

Rust masuk kernel

Bahasa yang lebih aman soal memori, mulai Linux 6.1.

2026Modern

Era Linux 7

Linux 7.0 rilis 12 April 2026. Versi baru terus hadir tiap 2–3 bulan.

03

FUNGSI

Apa yang Dikerjakan Linux?

Delapan tugas utama sistem operasi, lengkap dengan perintah untuk melihatnya.

Manajemen Proses

Mengatur program yang berjalan agar bisa multitasking.

ps aux

Manajemen Memori

Membagi RAM ke tiap program secara aman.

free -h

Manajemen File

Menyimpan dan mengatur file lewat file system seperti ext4.

ls -l

Mengelola Hardware

Menghubungkan keyboard, layar, USB, dan lainnya lewat driver.

lsusb

Keamanan & Akses

Mengatur siapa boleh mengakses apa.

id

Jaringan

Menghubungkan ke internet dan menjalankan server.

ip a

Antarmuka

Menyediakan terminal (CLI) dan desktop grafis (GUI).

echo $SHELL

Menjalankan Aplikasi

Memasang dan menjalankan software lewat package manager.

sudo apt install git

04

KARAKTERISTIK

Ciri Khas Linux

Pilih salah satu untuk melihat penjelasan dan contohnya di terminal.

KARAKTERISTIK 01

Open Source

Kodenya terbuka untuk siapa saja: boleh dipelajari, diubah, dan dibagikan di bawah lisensi GNU GPL v2. Celah keamanan pun lebih cepat ketahuan dan diperbaiki.

$ git clone https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git
Cloning into 'linux'...
KARAKTERISTIK 02

Multiuser

Banyak pengguna bisa memakai satu sistem bersamaan, masing-masing dengan akun, folder, dan izin sendiri.

$ who
tux      tty2     2026-11-18 08:02
admin    pts/0    2026-11-18 09:15 (192.168.1.7)
KARAKTERISTIK 03

Multitasking

Banyak program berjalan sekaligus. Kernel membagi waktu CPU dalam potongan sangat kecil, jadi semuanya terasa jalan bersamaan.

$ top -bn1 | head -2
top - 09:20:01 up 3 days,  2 users,  load average: 0.42, 0.37, 0.30
Tasks: 214 total,   1 running, 213 sleeping,   0 stopped
KARAKTERISTIK 04

Portabel

Satu kernel untuk banyak jenis prosesor: PC x86, ARM di HP dan Raspberry Pi, RISC-V, sampai superkomputer.

$ uname -m
x86_64
KARAKTERISTIK 05

File Berhierarki

Semua file tersusun seperti pohon dari satu akar, / (root). Tidak ada drive C: atau D:.

$ ls /
bin  boot  dev  etc  home  lib  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var
KARAKTERISTIK 06

Shell Powerful

Satu baris perintah bisa menggantikan puluhan klik, dan tugas berulang bisa diotomatisasi dengan script.

$ ls ~/Pictures/*.jpg | wc -l
128
KARAKTERISTIK 07

Izin File Ketat

Tiap file punya pemilik dan izin baca (r), tulis (w), jalankan (x). Tanpa izin root, file sistem tidak bisa diubah. Coba simulatornya di bawah.

$ ls -l /etc/shadow
-rw-r----- 1 root shadow 1450 Nov 18 08:00 /etc/shadow
KARAKTERISTIK 08

Case-Sensitive

Huruf besar dan kecil dibedakan: Tugas.txt dan tugas.txt adalah dua file berbeda.

$ ls
Tugas.txt  TUGAS.txt  tugas.txt
COBA SENDIRI

Simulator Hak Akses File

Centang izin untuk owner, group, dan others, lalu lihat hasilnya dalam simbol dan angka.

SiapaRead (r = 4)Write (w = 2)Execute (x = 1)
Owner
Group
Others
Simbol-rwxr-xr--
Angka (oktal)754
Perintahchmod 754 tugas.sh

Owner bisa membaca, menulis, dan menjalankan. Group bisa membaca dan menjalankan. Others hanya bisa membaca.

Hati-hati: semua orang bisa mengubah file ini. Izin seperti 777 sering jadi celah serangan.

KEUNGGULAN

Kenapa Memilih Linux?

Alasan Linux dipakai dari laptop mahasiswa sampai NASA.

01

Gratis

Tanpa biaya lisensi, di berapa pun komputer.

02

Aman

Izin ketat dan update cepat membuatnya sulit ditembus malware.

03

Stabil

Server bisa menyala berbulan-bulan tanpa restart.

04

Ringan

Distro seperti MX Linux atau Lubuntu menghidupkan lagi laptop lama.

05

Fleksibel

Tampilan sampai kernelnya bisa diatur sesuai selera.

06

Komunitas Besar

Hampir setiap masalah sudah ada solusinya di forum.

Linux vs Windows vs macOS

Perbandingan singkat dan jujur. Tiap sistem punya kelebihan sendiri.

AspekLinuxWindowsmacOS
Harga✓Gratis~Berbayar (lisensi)~Gratis, tapi wajib perangkat Apple
Kode sumber✓Terbuka✕Tertutup~Sebagian besar tertutup
Kustomisasi✓Sangat bebas~Terbatas~Terbatas
Perangkat✓Hampir semua PC, termasuk lama~Sebagian besar PC✕Hanya Mac
Ancaman malware✓Jarang jadi target~Paling sering jadi target✓Cukup aman
Software & game~Terbatas, sebagian lewat Proton✓Paling lengkap~Kuat di aplikasi kreatif

Biar Adil: Tantangannya

  • Beberapa software populer (Photoshop, MS Office) belum ada versi resminya; alternatifnya GIMP dan LibreOffice.
  • Sebagian game dengan anti-cheat belum bisa dimainkan.
  • Perlu waktu adaptasi, terutama dengan terminal.
