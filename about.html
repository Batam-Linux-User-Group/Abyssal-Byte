PENGERTIAN

Apa Itu Linux?

Sebelum lanjut, kita samakan dulu: sebenarnya Linux itu apa, dan kenapa ada yang menyebutnya "GNU/Linux"?

Linux adalah kernel sistem operasi yang bersifat open source, pertama kali dibuat oleh Linus Torvalds pada tahun 1991.

Kernel adalah inti dari sistem operasi, yaitu bagian yang menghubungkan software (aplikasi) dengan hardware (CPU, RAM, disk, dan perangkat lain). Tanpa kernel, aplikasi tidak bisa "ngobrol" dengan perangkat keras.

Dalam percakapan sehari-hari, kata "Linux" biasanya dipakai untuk menyebut sistem operasi lengkap: kernel Linux ditambah tools dari proyek GNU dan aplikasi lainnya. Karena itu ada juga yang menyebutnya GNU/Linux. Paket lengkap yang siap di-install disebut distribusi atau distro, contohnya Ubuntu, Debian, Fedora, dan Kali Linux.

Analogi gampangnya

Kernel Linux itu ibarat mesin mobil. Distro seperti Ubuntu atau Fedora adalah mobil utuhnya: mesinnya sama, tapi bodi, interior, dan fiturnya beda-beda tergantung "pabrikannya".

FUN FACT

Hampir Bernama "Freax"

Linus awalnya ingin menamai proyeknya Freax (gabungan free, freak, dan x dari Unix). Tapi Ari Lemmke, pengelola server FTP tempat kodenya diunggah, memberi nama folder linux. Nama itulah yang akhirnya dipakai sampai sekarang.

Maskotnya, penguin Tux, digambar oleh Larry Ewing pada 1996. Konon Linus pernah digigit penguin saat berkunjung ke kebun binatang di Australia.

02

SEJARAH

Perjalanan Linux dari Masa ke Masa

Linux tidak muncul tiba-tiba. Akarnya ada di Unix tahun 1969, lalu tumbuh berkat gerakan perangkat lunak bebas dan kolaborasi ribuan orang di internet.

1969Akar

Unix lahir di Bell Labs

Ken Thompson dan Dennis Ritchie membuat Unix di Bell Labs (AT&T). Konsep Unix seperti shell, sistem file hierarki, dan multiuser kelak jadi "cetak biru" Linux.

1983Akar

Richard Stallman memulai proyek GNU

Tujuannya membuat sistem operasi mirip Unix yang sepenuhnya bebas. Tools GNU seperti compiler GCC dan shell Bash kelak dipakai bersama kernel Linux.

1987Akar

MINIX dirilis untuk belajar

Andrew S. Tanenbaum membuat MINIX, sistem operasi mini mirip Unix untuk mengajar mahasiswa. Linus Torvalds memakai MINIX sebelum membuat Linux.

25 Agu 1991Kelahiran

Linus mengumumkan proyek "hobi"-nya

Linus Torvalds, mahasiswa Universitas Helsinki berusia 21 tahun, menulis di newsgroup comp.os.minix bahwa ia sedang membuat sistem operasi gratis, "just a hobby".

17 Sep 1991Kelahiran

Linux 0.01 dirilis

Versi pertama kernel Linux diunggah ke server FTP. Ukurannya baru sekitar 10.000 baris kode, sangat kecil dibanding sekarang.

1992Kelahiran

Memakai lisensi GNU GPL

Linux dirilis ulang dengan lisensi GNU GPL. Sejak itu kernel Linux dan tools GNU bisa digabung menjadi sistem operasi lengkap yang bebas dipakai, diubah, dan dibagikan.

1993Kelahiran

Distro pertama bermunculan

Slackware dan Debian lahir di tahun yang sama. Debian sampai sekarang jadi "induk" bagi Ubuntu, Kali Linux, dan banyak distro lain.

14 Mar 1994Kelahiran

Linux 1.0 resmi dirilis

Kernel versi 1.0 dianggap cukup stabil untuk dipakai sehari-hari dan sudah mendukung jaringan komputer.

1996Kelahiran

Tux jadi maskot & Linux 2.0 rilis

Penguin Tux digambar oleh Larry Ewing. Di tahun yang sama Linux 2.0 rilis dan mulai mendukung komputer dengan banyak prosesor (SMP).

2004Berkembang

Ubuntu hadir untuk semua orang

Ubuntu 4.10 rilis dengan misi membuat Linux mudah dipakai pemula. Sampai sekarang Ubuntu jadi salah satu distro paling populer.

2005Berkembang

Linus menciptakan Git

Butuh alat baru untuk mengelola kode kernel, Linus membuat Git. Sekarang Git dipakai jutaan developer di seluruh dunia, termasuk lewat GitHub yang dipakai kelompok kami.

2007Berkembang

Linux Foundation dibentuk

Organisasi nirlaba yang menaungi pengembangan Linux. Lewat yayasan ini Linus bisa bekerja penuh waktu mengurus kernel.

2008Berkembang

Android: Linux masuk ke saku

Ponsel Android pertama (HTC Dream / T-Mobile G1) rilis. Android dibangun di atas kernel Linux dan kini dipakai miliaran orang.

2011Berkembang

Linux 3.0 & ulang tahun ke-20

Linux merayakan usia 20 tahun dengan merilis versi 3.0. Saat itu Linux sudah menguasai server, superkomputer, dan smartphone.

Nov 2017Modern

Menguasai 100% superkomputer

Untuk pertama kalinya seluruh 500 superkomputer tercepat di dunia (daftar TOP500) memakai Linux, dan kondisi ini bertahan sampai sekarang.

2021Modern

Linux terbang di Mars

Helikopter Ingenuity milik NASA berhasil terbang di Mars sambil menjalankan Linux. Di tahun ini juga Linux genap berusia 30 tahun.

2022Modern

Bahasa Rust masuk ke kernel

Mulai Linux 6.1, kernel menerima kode Rust, bahasa yang lebih aman dalam mengelola memori, di samping bahasa C.

2026Modern

Memasuki era Linux 7

Setelah versi 6.19, Linus menaikkan nomor versi ke Linux 7.0 yang rilis 12 April 2026. Versi baru kernel terus rilis kira-kira setiap 2–3 bulan.

03

FUNGSI

Apa Saja yang Dikerjakan Linux?

Sebagai sistem operasi, Linux bekerja di balik layar mengatur semua hal. Di tiap kartu ada contoh perintah terminal yang bisa kamu coba (klik ikon untuk menyalin).

Manajemen Proses

Mengatur program yang sedang berjalan (proses): mana yang jalan duluan, berapa lama, dan kapan berhenti. Inilah yang membuat komputer bisa multitasking.

ps aux

Manajemen Memori

Membagi RAM ke setiap program secara adil dan memastikan satu program tidak bisa mengacak-acak memori milik program lain.

free -h

Manajemen File

Menyimpan, membaca, dan mengatur file serta folder di disk lewat file system seperti ext4 atau Btrfs.

ls -l

Mengelola Hardware

Lewat driver, kernel "mengajak bicara" keyboard, layar, USB, kartu jaringan, dan perangkat lain supaya bisa dipakai aplikasi.

lsusb

Keamanan & Hak Akses

Mengatur siapa boleh melakukan apa. Setiap file punya pemilik dan izin, dan tugas admin dibatasi lewat akun root atau perintah sudo.

id

Jaringan

Menghubungkan komputer ke internet atau jaringan lokal, termasuk menjalankan server web, SSH, dan firewall.

ip a

Antarmuka Pengguna

Menyediakan cara berinteraksi: lewat terminal (CLI) untuk perintah teks, atau lewat desktop grafis (GUI) seperti GNOME dan KDE Plasma.

echo $SHELL

Menjalankan Aplikasi

Menjadi "panggung" bagi aplikasi, sekaligus memudahkan install dan update software lewat package manager.

sudo apt install git

KARAKTERISTIK

Ciri Khas Linux

Hal-hal yang membuat Linux berbeda dari sistem operasi lain. Pilih salah satu karakteristik untuk melihat penjelasan dan contohnya di terminal.

KARAKTERISTIK 01

Open Source

Kode sumber Linux terbuka untuk umum. Siapa pun boleh melihat, mempelajari, memodifikasi, dan membagikannya lagi, selama mengikuti lisensi GNU GPL versi 2.

  • Bisa dipelajari langsung dari kodenya
  • Celah keamanan bisa ditemukan dan diperbaiki banyak orang
  • Tidak bergantung pada satu perusahaan saja
$ git clone https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git
Cloning into 'linux'...
KARAKTERISTIK 02

Multiuser

Satu sistem Linux bisa dipakai banyak pengguna, bahkan secara bersamaan (misalnya lewat SSH). Tiap pengguna punya akun, folder home, dan izin masing-masing.

  • File antarpengguna terpisah dan terlindungi
  • Cocok untuk server yang diakses banyak orang
  • Ada akun khusus admin bernama root
$ who
tux      tty2     2026-11-18 08:02
admin    pts/0    2026-11-18 09:15 (192.168.1.7)
KARAKTERISTIK 03

Multitasking

Linux bisa menjalankan banyak program sekaligus. Kernel membagi waktu CPU dalam potongan yang sangat kecil, sehingga semua program terasa berjalan bersamaan.

  • Dengar musik sambil coding sambil download
  • Program di latar belakang tetap jalan
  • Proses bisa dipantau dan dihentikan kapan saja
$ top -bn1 | head -2
top - 09:20:01 up 3 days,  2 users,  load average: 0.42, 0.37, 0.30
Tasks: 214 total,   1 running, 213 sleeping,   0 stopped
KARAKTERISTIK 04

Portabel

Linux bisa berjalan di banyak jenis prosesor dan perangkat: PC x86, ARM di smartphone dan Raspberry Pi, RISC-V, sampai mainframe dan superkomputer.

  • Satu kernel, banyak arsitektur
  • Bisa dipakai dari jam tangan pintar sampai server raksasa
  • Mudah diadaptasi untuk perangkat baru
$ uname -m
x86_64
KARAKTERISTIK 05

File Berstruktur Hierarki

Semua file tersusun seperti pohon terbalik yang berawal dari satu akar, yaitu / (root). Tidak ada drive C: atau D: seperti di Windows; disk lain "ditempelkan" ke folder tertentu.

  • /home berisi folder milik pengguna
  • /etc berisi file konfigurasi sistem
  • /bin dan /usr berisi program
$ ls /
bin  boot  dev  etc  home  lib  media  mnt  opt  proc  root  run  sbin  srv  sys  tmp  usr  var
KARAKTERISTIK 06

Everything is a File

Di Linux, hampir semuanya diperlakukan sebagai file, termasuk perangkat keras. Contohnya, disk muncul sebagai /dev/sda, dan info CPU bisa dibaca dari /proc/cpuinfo.

  • Perangkat bisa diakses dengan perintah file biasa
  • Info sistem bisa dibaca seperti membaca teks
  • Konsep ini diwarisi dari Unix
$ grep -m1 "model name" /proc/cpuinfo
model name      : AMD Ryzen 5 5600H with Radeon Graphics
KARAKTERISTIK 07

Shell yang Powerful

Terminal di Linux bukan sekadar "layar hitam". Dengan shell seperti Bash, satu baris perintah bisa menggantikan puluhan klik, dan tugas berulang bisa diotomatisasi dengan script.

  • Perintah bisa digabung dengan pipe |
  • Tugas rutin bisa dijadwalkan otomatis
  • Server bisa dikelola dari jarak jauh lewat SSH
$ ls ~/Pictures/*.jpg | wc -l
128
KARAKTERISTIK 08

Keamanan Berbasis Izin

Setiap file punya pemilik, grup, dan izin baca (r), tulis (w), dan jalankan (x). Pengguna biasa tidak bisa mengubah file sistem tanpa izin root. Coba simulatornya di bawah!

  • Malware sulit merusak sistem tanpa izin root
  • Data tiap pengguna saling terlindungi
  • Izin bisa diatur dengan perintah chmod
$ ls -l /etc/shadow
-rw-r----- 1 root shadow 1450 Nov 18 08:00 /etc/shadow
KARAKTERISTIK 09

Case-Sensitive

Linux membedakan huruf besar dan kecil. Tugas.txt, tugas.txt, dan TUGAS.txt dianggap tiga file yang berbeda. Begitu juga dengan perintah: ls bisa jalan, LS tidak.

  • Teliti saat mengetik nama file dan perintah
  • Biasakan memakai huruf kecil
  • Berlaku juga untuk nama folder
$ ls
Tugas.txt  TUGAS.txt  tugas.txt
KARAKTERISTIK 10

Modular & Bisa Dikustomisasi

Komponen Linux bisa "dibongkar pasang". Driver dimuat sebagai modul kernel saat dibutuhkan, dan tampilan desktop bisa diganti sesuka hati (GNOME, KDE Plasma, XFCE, dan lainnya).

  • Pasang hanya yang kamu butuhkan
  • Tampilan bisa dibuat mirip Windows atau macOS
  • Itulah sebabnya ada ratusan distro berbeda
$ lsmod | head -3
Module                  Size  Used by
bluetooth            1028096  12
snd_hda_intel          61440  4
COBA SENDIRI

Simulator Hak Akses File

Centang izin untuk owner (pemilik), group, dan others (orang lain). Lihat bagaimana Linux menuliskannya dalam bentuk simbol dan angka.

SiapaRead (r = 4)Write (w = 2)Execute (x = 1)
Owner
Group
Others
Simbol-rwxr-xr--
Angka (oktal)754
Perintahchmod 754 tugas.sh

Owner bisa membaca, menulis, dan menjalankan. Group bisa membaca dan menjalankan. Others hanya bisa membaca.

Hati-hati: semua orang bisa mengubah file ini. Di dunia keamanan siber, izin seperti 777 sering jadi celah serangan.

KEUNGGULAN

Kenapa Banyak yang Memilih Linux?

Dari mahasiswa sampai NASA, alasan memakai Linux biasanya kembali ke poin-poin berikut.

01

Gratis

Hampir semua distro bisa diunduh dan dipakai tanpa bayar lisensi, di berapa pun komputer yang kamu punya.

02

Transparan & Menghargai Privasi

Kodenya bisa diperiksa siapa saja, dan kebanyakan distro tidak menampilkan iklan atau memaksa pengumpulan data pengguna.

03

Lebih Aman

Sistem izin yang ketat, pemisahan akun root, dan update keamanan yang cepat membuat Linux lebih sulit diserang malware.

04

Stabil & Andal

Server Linux bisa menyala berbulan-bulan tanpa restart. Itulah alasan Linux dipercaya untuk server dan superkomputer.

05

Ringan

Distro ringan seperti MX Linux, Lubuntu, atau Linux Lite bisa "menghidupkan" lagi laptop lama yang sudah lemot.

06

Bebas Dikustomisasi

Mulai dari tampilan desktop, ikon, sampai kernelnya sendiri bisa diubah sesuai selera dan kebutuhan.

07

Komunitas Besar

Forum, dokumentasi, dan grup diskusi tersebar di seluruh dunia, jadi hampir setiap masalah sudah ada solusinya.

08

Install Software Mudah

Package manager (apt, dnf, pacman) membuat install dan update aplikasi cukup dengan satu perintah, langsung dari sumber resmi.

09

Rumahnya Developer & Cyber Security

Banyak tools pemrograman, server, dan keamanan siber dibuat untuk Linux lebih dulu, jadi skill Linux sangat dicari di dunia kerja IT.

Linux vs Windows vs macOS

Perbandingan singkat dan jujur. Setiap sistem operasi punya kelebihan masing-masing.

AspekLinuxWindowsmacOS
Harga✓Gratis untuk hampir semua distro~Berbayar (lisensi), sering sudah termasuk saat beli laptop~Gratis, tapi harus membeli perangkat Apple
Kode sumber✓Terbuka (open source)✕Tertutup~Sebagian besar tertutup
Kustomisasi✓Sangat bebas, sampai ke kernel~Terbatas~Terbatas

Biar Adil: Tantangan Memakai Linux

  • Beberapa software populer seperti Adobe Photoshop dan Microsoft Office belum punya versi resmi untuk Linux (alternatifnya: GIMP dan LibreOffice).
  • Sebagian game dengan sistem anti-cheat tertentu belum bisa dimainkan.
  • Perlu waktu adaptasi, terutama untuk terbiasa dengan terminal.
  • Driver beberapa perangkat (misalnya printer atau Wi-Fi tertentu) kadang perlu diatur manual.
