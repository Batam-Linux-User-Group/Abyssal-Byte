Linux Installation

Install Linux dengan Aman

Pilih cara install, siapkan perangkat, lalu ikuti langkahnya. Contoh langkah memakai Ubuntu, distro yang paling ramah pemula.

  • ± 30–60 menit
  • Flashdisk 8 GB
  • Ramah pemula
  1. Download ISO
  2. Buat USB bootable
  3. Boot dari USB
  4. Install & selesai

Langkah 0

Pilih Cara Install

Tidak harus langsung menghapus Windows. Jawab dua pertanyaan ini untuk rekomendasi.

Masih mau pakai Windows?
Tujuanmu?

Pilih jawaban di atas, rekomendasinya akan disorot di bawah.

Paling aman

Virtual Machine

Linux berjalan di dalam aplikasi seperti VirtualBox, di atas Windows.

  • Data laptop tidak tersentuh
  • Performa lebih lambat
Tanpa install

Live USB

Jalankan Linux langsung dari flashdisk untuk mencoba.

  • Tidak mengubah apa pun
  • Perubahan hilang saat restart
Butuh hati-hati

Dual Boot

Linux dan Windows terpasang berdampingan, pilih saat menyalakan.

  • Performa penuh
  • Perlu membagi partisi
Hapus semua data

Install Penuh

Linux menggantikan sistem operasi lama sepenuhnya.

  • Paling simpel & maksimal
  • Isi disk terhapus
Pakai Windows 10/11? Coba WSL.

Linux bisa jalan langsung di Windows. Buka CMD atau PowerShell sebagai Administrator, lalu ketik:

wsl --install

Langkah 2

Langkah Instalasi

Contoh memakai Ubuntu. Distro lain alurnya mirip.

Download Ubuntu
  1. 1

    Download ISO

    Unduh dari situs resminya. Pilih versi LTS karena paling stabil.

  2. 2

    Buat USB bootable

    Buka Rufus atau balenaEtcher, pilih file ISO dan flashdisk, lalu klik Start / Flash.

  3. 3

    Masuk boot menu

    Restart laptop, tekan tombol boot menu (lihat tabel), lalu pilih flashdisk.

  4. 4

    Coba atau install

    Pilih Try Ubuntu untuk mencoba, atau Install Ubuntu untuk lanjut.

  5. 5

    Atur bahasa & jaringan

    Pilih bahasa, layout keyboard, lalu sambungkan Wi-Fi.

  6. 6

    Pilih jenis instalasi

    Install alongside Windows untuk dual boot, atau Erase disk untuk install penuh.

    Erase disk menghapus semua data di disk.

  7. 7

    Buat akun

    Isi nama, username, dan password. Ingat baik-baik, password ini juga dipakai untuk sudo.

  8. 8

    Restart & update

    Cabut flashdisk saat diminta, lalu perbarui sistem:

    sudo apt update && sudo apt upgrade -y

Langkah 3

Tombol Boot Menu

Tekan berulang kali tepat setelah laptop dinyalakan. Bisa berbeda per model.

ASUSEscF8
AcerF12
LenovoF12
HPEscF9
DellF12
MSIF11
ToshibaF12
Masuk BIOSF2Del

Tidak muncul? Masuk BIOS, lalu pindahkan flashdisk ke urutan boot pertama dan matikan Fast Boot.

Langkah 4

Setelah Install

Empat hal pertama yang sebaiknya dilakukan.

Update sistem

sudo apt update && sudo apt upgrade

Aktifkan firewall

sudo ufw enable

Pasang aplikasi

sudo apt install vlc git

Cek driver tambahan

Buka Software & Updates → tab Additional Drivers.

FAQ

Pertanyaan yang Sering Muncul

Apakah data Windows hilang kalau dual boot?

Tidak, selama kamu memilih Install alongside Windows. Tetap backup dulu untuk jaga-jaga.

Bisa mencoba Linux tanpa flashdisk?

Bisa, lewat VirtualBox atau WSL di Windows.

Distro apa yang cocok untuk pemula?

Ubuntu, Linux Mint, atau Zorin OS. Bandingkan di bagian Distributions.

Laptop tidak mau boot dari flashdisk?

Cek urutan boot di BIOS, matikan Fast Boot, lalu buat ulang USB bootable. Untuk sebagian distro, Secure Boot juga perlu dimatikan.

Berapa lama prosesnya?

Sekitar 15–30 menit untuk instalasi, belum termasuk waktu download ISO.
